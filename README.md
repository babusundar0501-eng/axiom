# AXIOM

Free browser-first AI app builder. Users describe an app, AXIOM creates an App Blueprint, renders a preview, and exports a standalone HTML app.

## Principles
- No API key required from users.
- Provider secrets stay server-side.
- Browser-first; the MVP needs no Node.js.
- AI plans into a structured Blueprint before code generation.
- Long-term goal: build AXIOM Brain from fundamentals.

## Roadmap
1. Builder foundation
2. Blueprint schema
3. Code generator
4. Project/file system
5. AI gateway
6. Tokenizer, embeddings, neural network, attention and transformer experiments
7. Local/open model support
8. Publishing and deployment
